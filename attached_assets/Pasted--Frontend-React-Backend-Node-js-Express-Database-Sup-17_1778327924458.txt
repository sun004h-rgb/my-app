청년일자리도약장려금 관리 시스템 웹사이트를 만들어줘.

기술스택:

* Frontend: React
* Backend: Node.js + Express
* Database: Supabase(PostgreSQL)
* UI: Tailwind CSS
* Authentication: 관리자 로그인
* Slack Incoming Webhook 연동
* Render 배포 가능 구조로 생성

목표:
운영기관이 청년일자리도약장려금 사업장을 관리하고 근로자별 회차 신청 및 알림을 관리할 수 있는 실무형 웹 시스템 제작.

[1. 로그인 및 권한]

* 관리자 로그인 기능
* 세션 유지
* 담당자별 권한 관리
* 담당자는 본인 담당 사업장만 조회/수정 가능
* 관리자 계정은 전체 사업장 조회/수정 가능
* 권한 없는 사업장 접근 차단

권한 종류:

* 관리자(admin)
* 담당자(manager)

[2. 사업장 관리]

사업장 등록/수정/삭제 가능.

사업장 필드:

* 사업장명
* 대표자명
* 사업자번호
* 설립일
* 대표자 주민등록번호
* 대표자 연락처
* 공동인증서 비밀번호
* 담당자명
* 운영기관명
* 운영기관 연락처
* 사업신청년도
* 입금은행명
* 계좌번호

사업신청년도 기능:

* 최소 2024년도부터 선택 가능
* 현재년도 이후 연도까지 확장 가능
* 드롭다운(select) 형태 구현
* 하드코딩 금지
* 현재 연도 기준 자동 생성
* 시작년도: 2024
* 종료년도: 현재년도 + 3년

예시:

* 2024년 신청 사업장
* 2025년 신청 사업장
* 2026년 신청 사업장
* 2027년 신청 사업장

사업신청년도 기준 필터:

* 단일 연도 필터
* 다중 연도 필터 가능하도록 설계

기능:

* 사업장 검색
* 사업신청년도 필터
* 담당자별 필터
* 상태별 필터

[3. 근로자 관리]

사업장 내부에 근로자 등록 가능.

근로자 필드:

* 이름
* 입사일
* 주민등록번호
* 중간입사자 여부
* 상태

  * 재직중
  * 중도퇴사
  * 지원금 종료

퇴사처리 기능 포함.

퇴사 정보:

* 퇴사일
* 퇴사사유
* 퇴사 후 신청 가능 여부 자동 계산

기능:

* 근로자 검색
* 상태 필터
* 회차 필터

[4. 회차 자동 생성 로직]

회차:

* 1회차
* 2회차
* 3회차

기본 지급금액:

* 1회차: 360,000원
* 2회차: 180,000원
* 3회차: 180,000원

일반 입사자:

* 1회차 = 입사일 + 6개월
* 2회차 = 입사일 + 9개월
* 3회차 = 입사일 + 12개월

중간 입사자인 경우:

* 1회차 = 입사일 + 7개월
* 2회차 = 입사일 + 10개월
* 3회차 = 입사일 + 13개월

[5. 중복 생성 방지]

* 동일 근로자 + 동일 회차 중복 생성 금지
* 동일 사업장 중복 등록 방지
* 사업자번호 중복 등록 방지
* 주민등록번호 중복 등록 체크
* 회차 생성 시 unique validation 적용

[6. 지원금 신청 상태]

회차별 상태:

* 신청 예정
* 신청 완료
* 지급 완료
* 미신청
* 퇴사
* 신청 불가

규칙:

* 1회차 도래 전 퇴사 시 신청불가 처리
* 1회차 지급 후 퇴사자는 일할 계산 금액 입력 가능
* 중도퇴사자 금액 직접 입력 가능
* 2회차 미신청 시 3회차에서 일괄신청 가능
* 3회차 화면에서 2회차 미신청 여부 표시
* 신청 가능 여부 자동 계산

[7. 슬랙 알림]

Slack Incoming Webhook 사용.

알림 시점:

* 신청 도래 7일 전
* 신청 도래 당일
* 미완료 3일 후 재알림

알림 내용:

* 사업장명
* 근로자명
* 회차
* 신청 예정 금액
* 신청 도래일
* 담당자명

슬랙 알림 클릭 시:

* 해당 근로자 상세페이지로 바로 이동 가능하도록 URL 포함

예시:

* 홍길동 1회차 신청 필요
* 클릭 시 근로자 상세페이지 이동

[8. 메인 대시보드]

메인 대시보드 표시:

* 사업신청년도별 사업장 수
* 회차별 신청 진행 수
* 당월 지원금 신청 진행 건수
* 당월 지원금 수수료 입금 완료 금액
* 미완료 신청 건수
* 금주 신청 예정 건수
* 담당자별 진행 현황

차트 UI 포함.
